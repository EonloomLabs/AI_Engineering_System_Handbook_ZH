# 工程深挖

入口：`index.html`。56个问题在系统篇对应Q问题后，8个案例在专题研修相应机制后。

- `sources.json`：一手来源、版本、核对日期和适用范围。
- `modules.json`、`cases.json`、`manuscript/`：可编辑的中文原稿。
- `labs/`：本次新增完整实验代码。
- `results/run.json`：真实环境、观察、代码指纹。
- `results/test.log`：实际运行日志。
- `placement.json`：正文插入位置清单。

不需要联网即可阅读中文全文。外部链接只用于复核来源；不是阅读替代。自检答案默认收起。
