# 界面审查与修正记录

## 先确定方向，再实现
采用技术参考文档，而非营销落地页的阅读目标。主阅读流程是进入课程、定位章节、查阅公式、操作图解、返回上下文。
设计规范先于页面实现保存于 DESIGN.md；先完成首页、F11 与 F31 样板，查看桌面与手机截图后再统一全站。

## 第一轮：旧界面
- 在真实本地内容渲染中，F31 的当前项位于约 y=1649，超出目录可视区；目录没有独立状态恢复逻辑。
- 首页大衬线标题和深绿色整块图形优先于阅读入口，更像介绍页面。
- 阅读页大面积浅绿色容器互相竞争，术语、前置知识、运行示例缺少轻重层次。

## 第二轮：样板
- 首页改成课程路径、辅助工具、十二个主题与运行导览。使用中性灰白、统一无衬线字体、单一蓝色定位信息。
- 阅读页统一为左侧书目、中央正文、宽屏右侧章节提纲。减少侧栏文字长度，完整名称保留在链接 title 中。
- F31 所属组自动展开，当前项进入左侧可视区。明确将目录头部与滚动内容分开，定位不改变正文位置。
- 去掉首页重复的标题分隔线，降低辅助文字的灰度，保证导航文字清晰。

## 第三轮：交互与兼容性修正
- 截图发现原基础样式的 body.nav-open .sidebar {display:block} 会破坏手机滚动容器的 flex 布局，已明确覆盖为 flex，并补充容器实际可视区检查，避免只比较一个过高的“内部视口”。
- 单文件版的 scroll-padding 与 scroll-margin 叠加造成章节跟随晚一章，已消除重复偏移，并回归验证 F31 与系统第25章的跨区段定位。
- 检查目录手动滚动不被正文滚动打断、刷新恢复、pageshow 恢复、禁用持久存储、精确路径匹配、抽屉焦点、Esc、搜索、字号和原生自检答案。

## 视觉原则与限制
- 主文/背景对比约15.02:1；辅助文字/白底约6.11:1；当前蓝色文字/浅蓝背景约5.84:1。对比率是计算值，不代表整站无障碍认证。
- 不在休止状态添加阴影、玻璃、渐变或装饰动画。教学图解仍由读者主动播放。
- 没有虚构设计师、设计机构或主观评分。最终效果由实际截图和可操作文件展示。
- 本环境禁止 file:// 与本地 HTTP 浏览器导航；用内联本地文件检查真实 Chromium 布局和脚本。文件依赖另作静态验证，未宣称已在用户 Mac/Safari 实机验证。
