AI 系统工程：从基础到内部

使用
完整解压压缩包，打开本文件夹的 index.html。无需安装依赖、启动服务器或登录。
complete.html 为单文件连续阅读版，正文、样式、搜索和动态图解已内联。
Python 源码与原始计算结果保留在相应实验目录；阅读 HTML 不要求运行 Python。

目录
桌面左侧始终显示章节目录；手机点击左上角菜单打开。
当前章节自动高亮并保持在目录可视区域。拖动目录可自由查看其他章节，
点击“定位当前”即可回到正在阅读的章节。目录滚动与正文滚动互不影响。
单文件阅读版根据正文区段更新左侧当前章节。

阅读控制
Ctrl / Command + K 打开搜索；Esc 关闭搜索、阅读设置或目录抽屉。
阅读设置中可以调整字号、行宽与中性纸面。设置仅保存在本机浏览器。
如果浏览器禁止本地存储，历史设置可能无法跨页面或跨会话保存；
当前章节仍可自动定位，不依赖存储才能工作。
正文完整展开，课后自检答案默认收起；图解默认暂停，按步骤查看或主动播放。

页面设计与检查
见 design/DESIGN.md、design/CHANGELOG.txt、design/QA.json。
正文与数值文件的保留情况、静态引用、浏览器检查均有独立记录。
