Giả sử đọc được mã giảng dạy sau:

from fnmatch import fnmatchcase

def excluded(path, patterns):
    return any(fnmatchcase(path, pattern) for pattern in patterns)

def select_files(root, files, patterns):
    return [p for p in files if not excluded(str(p), patterns)]

Chưa thể khẳng định không dùng root là lỗi duy nhất. Xác nhận files là đường tuyệt đối hay tương đối, ngữ nghĩa patterns và dấu phân cách. Tham số không dùng là manh mối, không chứng minh nguyên nhân.
