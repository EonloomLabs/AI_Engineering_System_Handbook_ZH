11872	From text to tokens and vectors
7819	An LLM first converts text into token IDs. A token may be a word, part of a word, punctuation, whitespace or a byte fragment; there is no fixed ratio between Chinese characters and tokens. The same text can have different lengths under different tokenizers; counting requires the implementation matched to the target model.
17968	A common pipeline includes normalization, pretokenization, a subword model and postprocessing. BPE progressively merges frequent fragments; other methods use different objectives. Do not assume every tokenizer lowercases text, or arbitrarily remove code whitespace to reduce tokens. The magnitude of an ID does not express semantic distance.
25062	With vocabulary size V and hidden dimension d, the embedding matrix has shape V×d. Looking up a row by ID gives an initial representation. It is not a fixed definition; later layers update the representation based on context. Static Word2Vec usually gives a word entry a fixed vector; contextual representations in a Transformer change with the sentence.
22374	The full attention computation
25641	Let the current representation X have n positions and d features. Projection gives Query, Key and Value:
8470	Q matches other positions, K is what gets matched, and V supplies content to combine. M is the mask: causal generation blocks access to future tokens, usually by setting the corresponding scores to negative infinity. Attention is an internal weighted computation, not a database query or a search-engine call.
14274	Original calculation:</strong> scores [0,1,2] give softmax probabilities of approximately [0.090,0.245,0.665]. If one Value dimension is [10,20,30], the output is approximately 25.75. This combines content and need not copy the position with the highest weight. The largest attention weight is not the complete reason for the decision either, because multiple heads, residuals and subsequent layers also contribute.
16225	Multi-head attention computes in different projection spaces and concatenates the results. Giving each head a fixed name such as "syntax head" or "fact head" does not provide a complete explanation. The original paper proposed an encoder–decoder architecture; a GPT-style causal decoder is organized differently, and their diagrams must not be conflated.

11908	From hidden states to the next token
20538	The final hidden representation passes through an output projection to produce logits over the vocabulary, then a probability transformation and decoding select a token. Logits are not calibrated factual confidence. The autoregressive factorization is:
28187	The newly selected token joins the subsequent prefix, and the loop continues until normal completion, a tool call, the budget limit or an external interruption. 7909	MHA, MQA, GQA and MoE
7912	MHA usually provides separate KV for different query heads; MQA shares one KV group; GQA shares KV among groups of query heads. MoE is sparsity at another level: a router chooses a few expert networks to process a token, rather than several chat agents holding a meeting. Total parameters and active parameters are also different quantities.
7847	Llama3, DeepSeek-V3 and Qwen3 provide different system cases. When reading reports, distinguish architecture, data, training, post-training and serving optimizations. Do not attribute overall performance to one component or treat historical technical reports as a current leaderboard.
