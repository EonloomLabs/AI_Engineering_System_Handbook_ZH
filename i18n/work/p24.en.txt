13798	Paging</strong> cuts the cache into fixed-size blocks and uses a mapping table to remember which physical block each sequence's logical block corresponds to, which helps manage requests of different lengths and shared prefixes. 13113	Key difference:</strong> PagedAttention keeps the logical positions contiguous while letting the physical blocks be scattered, which cuts waste in allocation.
