11170	Do not take retrieval similarity for logical entailment
21567	Retrieval judges "this passage has to do with the question"; a citation points at "where this material comes from"; a support judgment asks "can this passage, under these conditions, yield the current conclusion". None of the three can stand in for another. Rank fusion only combines relevance signals; it does not check the conditions of use for each proposition in the answer.
15786	A fixed counterexample: the material says "Pro version 3 allows a limit of 100", and the user asks "does Free version 3 allow 100". The title and the version are both highly relevant and the citation is genuine, but the tier condition does not match, so it cannot support "allowed". This book's local condition check returns false; this is not a judgment that relies on a language model's score.
18734	Break one sentence into propositions with conditions
12297	For example, "the feature is on by default and costs nothing extra" contains two propositions, which may need the configuration document and a billing basis respectively. An evidence table should record the proposition, the source range, the version, the time it took effect, who it applies to, the supporting or opposing relationship, and the unknowns. Keep as unknown whatever the source does not contain; do not use fluent language to fill it in as a conclusion.
20317	Time matters especially: an old document and a new one disagreeing about the same feature may mean the effective period changed, not that one of them is a fake. Research on long-term memory also treats temporal reasoning and knowledge updating as a separate capability.
5890	 The difference between the question as it was then and as it is now should be preserved.
21188	The order in which conflicting sources are handled
12819	First check whether they are discussing the same object, version and conditions; then look at the original source, the publication time and whether it was formally withdrawn later. 10976	No. A model can attach a genuine source to a sentence that the source does not support. 22928	When the user has only one vague question while the corpus is detailed technical prose, HyDE generates a hypothetical document and encodes that, which may narrow the gap in wording.
