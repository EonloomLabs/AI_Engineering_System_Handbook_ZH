22783	Symptom: the agent says the edit is complete, but tests still fail.
12814	First check that the goal is clear and the tests really match the current requirements; then compare the final working tree with the version the agent read; check whether the tool response matches the actual files; then see whether the model read the key callers; only then analyze the reasoning or algorithm implementation.
