# 翻译过程中发现的中文原文问题（均未擅自改动中文）

1. index.html「从F01开始 →」指向 foundations/01.html，而那是第35课；第01课是 foundations/22.html。
   阅读顺序走课号（pager: chapters/25 → foundations/01 → foundations/02 即 34→35→36）。
   同页上方 data-i18n 的 CTA 指向正确。

2. chapters/07.html 裸字母 M：`已经训练好的M权重…`、`本M`（共 3 处，全书仅此页）。
   该页符号表把 M 定义为掩码，不是模型。两个译者独立判断它指贯通模型，但都保留裸字母未作断言。

3. chapters/17.html `追问：全仓索引更新完再允许Agent工作是否最安全？`
   答案 `会降低延迟且可能阻塞不必要的任务。` —— 整段论证不要等全量索引，
   但「降低延迟」是收益，与并列的「阻塞不必要的任务」方向相反。疑为「增加延迟」之误。
   英文已按原文忠实翻译（lowers latency），未代为修正。

4. chapters/18.html E35：正文说「第8天」，实验记录字段为 E35.at_day6_known_day9。
   中文自身不一致，英文按正文忠实翻译。

5. chapters/18.html `100元`：英文作 "100 yuan"，但邻近边界说明称数字是
   「虚构的统一单位，不是任何厂商现价」。若改为 "units" 属编辑决定。

6. chapters/24.html key 26405：`版本包V1={贯通模型1,提示P1,工具T1,索引I1}；V2同时升级为M2/P2/T2/I2`
   其余三项是 P1/T1/I1，V2 的是 M2/P2/T2/I2，首项疑应为「模型M1」，「贯通模型」像是误替换。
   英文已按原文直译。

7. `元` 作货币单位共 3 处（20元 / 100元 / 每次1元），邻近声明称数字是虚构统一单位。
   现译 "yuan"。若改为抽象 "units" 属编辑决定，三处应一并处理。

8. `<code>` 内中文（已知缺口，5.6 万字）里有两类会直接影响阅读：
   - chapters/25.html `max(3,5)+2=7秒` —— 单位「秒」留在英文页
   - chapters/28.html `模型提议 --必须经校验--> 执行器` —— Mermaid 图源整句中文
   - chapters/16.html `[query,document]→联合模型→相关性分数`
   - chapters/26.html `平均(pᵢ−yᵢ)²` —— 「平均」留在 Brier score 句尾

9. foundations/08.html `<strong>` 嵌套错误（标签数配对，所以计数检查查不出来）：

   `<strong>步长（stride）<strong>描述…可能是原数据的</strong>视图（view）</strong>`

   第二个 `<strong>` 应为 `</strong>`。实际效果是从「步长」到「视图」整段加粗，
   而非只加粗两个术语。全站扫描只此一处。
   英文版按原文逐字保留标签，所以同样继承这个加粗范围。
