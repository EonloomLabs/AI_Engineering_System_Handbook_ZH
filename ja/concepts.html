まずXWを中国語の一文で読み、その後、行列のサイズを見る

Y=XW「Xの各行を、Wの各列が与える係数で組み合わせ、Yの各列を作る」と読みます。例えば、Xが二行で各行に三つの数、Wが三行で各行に二つの数を持つとします。

X[2,3] @ W[3,2] → Y[2,2]
Y[i,j] = X[i,0]W[0,j] + X[i,1]W[1,j] + X[i,2]W[2,j]

Wq、W_Qと、一部の資料のW^Qは、いずれもクエリの射影パラメーターの名前に使われる可能性があります。これらは表記方法であり、三種類の独立したアルゴリズムではありません。逆に、同じ見た目の文字でも、別の章では異なる役割を担う場合があります。そのため、本書は文字の外観で、その場の定義を代用しません。

Norm(X)は正規化の演算の呼び出しを、FFN(X)はフィードフォワードネットワークの呼び出しを、softmax(S)は指定した軸に沿ってスコアを割合に変える処理の呼び出しを表します。関数は内部で学習可能なパラメーターを使うことがありますが、関数名そのものは重みの列ではありません。

基礎からシステムへの依存関係の経路

モデル計算の経路： 数の入れ物と形状 → トークンIDとEmbedding → 行列積 → パラメーターと中間結果 → Query/Key/Value → スコアと読み取りの割合 → マスクと位置 → マルチヘッド・出力の射影・残差・フィードフォワード → 出力トークンとキャッシュ。

学習の経路： 順伝播の結果 → 正解ラベルと損失 → 導関数と連鎖律 → 各パラメーターの勾配 → オプティマイザーの状態と更新 → 事後学習の目標。微分が分からなくても、まずWが順伝播にどう関わるかを理解できます。「重みは学習で得る」を、「すべての強化学習アルゴリズムを先に理解する必要がある」と誤解しないでください。

エージェントの経路： リクエストと構造化データ → モデルの出力項目 → ツール呼び出しの識別子 → 権限と実行 → イベントと状態 → コンテキストの再構築 → コンパクションからの復元 → マルチエージェントの協調。

知識と品質の経路： 元の証拠 → 分割とインデックス作成 → 候補取得とリランキング → バージョンと権限 → 生成と引用 → 記憶のライフサイクル → 確認可能なタスクの結果 → 統計的な比較と実行コスト。

新しい仕組みを学ぶときは、「入力はどの対象か、パラメーターはどこから来るか、実際に何を計算するか、結果をどの段階で使うか」に答えてから、式に進みます。下の概念インデックスは、本書で混同しやすい用語について、その場で読める定義・独立した小さな例・対応する完全な課を示します。

c=xW_downを読むとき、cは今回の計算の潜在ベクトル、W_downは学習した次元削減の係数表です。その後の再構成や投影の吸収は、具体的なアーキテクチャに沿って説明する必要があります。
