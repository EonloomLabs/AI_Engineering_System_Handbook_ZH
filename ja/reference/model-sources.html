確認日：2026年10月21日。インターフェースの説明は指定のバージョンを基準とし、これらをすべての製品の最新バージョンとは呼びません。本文を読むのにネット接続は不要で、リンクは一次資料の確認に使います。計算例、導出、通しのモデルは本教材が独自に構成し、元の論文の結果とローカルの実測を分けています。

ATTENTION · Attention Is All You Need

元の論文のアーキテクチャ、スケーリングした内積アテンション、フィードフォワード、学習の仕組みです。本書の通しのモデルは、論文の元のエンコーダー—デコーダーではありません。

LINEAR · PyTorch 2.10 · Linear

ADAMW · PyTorch 2.10 · AdamW

DROPOUT · PyTorch 2.10 · Dropout

SDPA · PyTorch 2.10 · scaled_dot_product_attention

AMP · PyTorch 2.10 · Automatic Mixed Precision examples

実験範囲

通しのモデルは、236パラメーターのCPU float64の教育用Decoderであり、二つの固定した系列だけに適合します。商用モデルのAPI、GPUの性能、SFT/RLHFの学習、自然言語の汎化評価は含みません。パラメーター、勾配、キャッシュ、生成の結果は、同梱のプログラムで生成します。図表の時間順序は、実際の所要時間を表しません。

訂正の限界

本書では、式に関する事実、インターフェースの規約、手作業の教育用初期値、ローカルの実際の実行、独立した工学的な導出を区別します。本書の他の部分にすでにある各バージョンの説明は保持し、今回の確認によって、過去の資料がすべて最新だと自動的に主張するものではありません。
