# AIシステム工学：基礎から内部へ

[简体中文](README.md) · [English](README.en.md) · **日本語** · [Español](README.es.md) · [Tiếng Việt](README.vi.md)

オフライン教材 · 基礎概念・内部の仕組み・エンジニアリングの実践

基礎から内部へ。大規模言語モデルが入力を処理して出力を生成する仕組みを理解し、エージェントによるツールの利用、コンテキストと記憶の管理を学び、検証可能な方法で開発品質を改善します。

## 開き方

展開して [`ja/index.html`](ja/index.html) を開きます。サーバー、ネットワーク、モデル API や鍵は必要ありません。
各ページのヘッダーにある言語切り替えから、同じページの他言語版へ直接移動できます。

## 構成

主軸は 5 つの段階と 68 課です。まずシステムを観察し、次に層をたどってモデル内部へ進み、最後にスタック全体の受け入れへ戻ります。

| 段階 | 課 | 内容 |
| --- | --- | --- |
| システムの観察 | 第 01—06 課 | 変更を語る前に、1 回のタスクの実行過程を確認できる証拠にする |
| ループの構築 | 第 07—28 課 | ツール呼び出し、コンテキスト、検索、記憶、失敗からの復帰 |
| ブラックボックスの最適化 | 第 29—34 課 | モデルを開けずに、権限・固定したタスク・完全な計時で最適化の効果を判断する |
| モデルの掌握 | 第 35—63 課 | サービスのインターフェースからテンソル、順伝播、学習、推論、さらに GPU とスケジューリングへ |
| スタック全体の検証 | 第 64—68 課 | マルチモーダル、不確実性、層をまたぐ最適化を同じ受け入れ基準に戻す |

基礎編の 40 課には自己確認問題があり、システム編の 28 章は 112 の主要な問いを軸に展開します。基礎がある場合は、12 の読書テーマから具体的な問題として入れます。
本文・図解・式の説明は展開済みで、自己確認の答えは既定で折りたたまれています。

## 数値の再計算

ネットワーク、GPU、API 鍵は不要です。Python 3.10 以上で、展開したディレクトリで実行します。

```bash
python3 worked-examples/run_all.py
```

実行できるコードとモデルのデータはリポジトリ直下にあり、全言語版で共用します。スクリプトのコメントと出力は中国語です。
例を変えたら再実行し、図・文章・検索・連続版もあわせて更新します。取り決めは [`AGENTS.md`](AGENTS.md) にあります。

## 検証の限界

401 の教育用の例は、401 回のモデル能力の実験ではありません。数値の式、次元、因果性、勾配、プロトコルの分割片、簡略化した状態の挙動はテストで確認します。ほかのシナリオ例は、前提を与えて明示的に推論します。
これらは商用エージェントの効果、GPU の速度、閉鎖されたソースの内部、本番の安全性を証明しません。
出典は実際のファイル・関数・行番号を指します。工学的な導出、実測、教育用の模擬は別々に示します。
数値図の丸めは表示のためだけで、計算は元の精度で行います。

出典確認の範囲は [`engineering/agent-evidence.html`](engineering/agent-evidence.html)、機械的な記録は `engineering/agent-practice/verified/` にあります。
