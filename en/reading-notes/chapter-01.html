Tokens, vectors, attention, the Transformer and token-by-token generation

From text to tokens and vectors

An LLM first converts text into token IDs. A token may be a word, part of a word, punctuation, whitespace or a byte fragment; there is no fixed ratio between Chinese characters and tokens. The same text can have different lengths under different tokenizers; counting requires the implementation matched to the target model.[S007]

A common pipeline includes normalization, pretokenization, a subword model and postprocessing. BPE progressively merges frequent fragments; other methods use different objectives. Do not assume every tokenizer lowercases text, or arbitrarily remove code whitespace to reduce tokens. The magnitude of an ID does not express semantic distance.

With vocabulary size V and hidden dimension d, the embedding matrix has shape V×d. Looking up a row by ID gives an initial representation. It is not a fixed definition; later layers update the representation based on context. Static Word2Vec usually gives a word entry a fixed vector; contextual representations in a Transformer change with the sentence.[S010][S008]

The full attention computation

Start with the objects and symbols used here
Query, Key, Value: three intermediate numeric representations
q is one row of query representation for the position receiving information; k is one row of matching representation offered by a readable position; v is one row of content representation that position contributes to the mix. Capital Q/K/V collect several rows into tables. They are computed from the input and the parameters, and they carry the separate jobs of scoring and of supplying content. One q dotted with two k gives two scores; softmax turns them into two shares; those shares multiply the two rows of v, and the results are added. Nothing here generates a search term, and nothing here picks an answer directly.

Let the current representation X have n positions and d features. Projection gives Query, Key and Value:

Start with the objects and symbols used here
d_k, d_v, Dh: the width of each row of representation
d_k is how many components one Query/Key vector has; d_v is how many components one Value vector has. Dh, or d_h, is the single-head width in some chapters. They are size integers, not the k-th Key or some Value number. Shape micro-example: with Q[2,3], K[5,3] and V[5,4], the scores are [2,5] and the output [2,4]. A pairing width of 3 for Q/K with a Value width of 4 is still legitimate.
Q = XW_Q，K = XW_K，V = XW_V
A = softmax(QKᵀ / √d_k + M)
Attention(X) = AV

Q matches other positions, K is what gets matched, and V supplies content to combine. M is the mask: causal generation blocks access to future tokens, usually by setting the corresponding scores to negative infinity. Attention is an internal weighted computation, not a database query or a search-engine call.[S008][S009]

Original calculation: scores [0,1,2] give softmax probabilities of approximately [0.090,0.245,0.665]. If one Value dimension is [10,20,30], the output is approximately 25.75. This combines content and need not copy the position with the highest weight. The largest attention weight is not the complete reason for the decision either, because multiple heads, residuals and subsequent layers also contribute.

Start with the objects and symbols used here
Concat, split and chunk: joining and splitting
Concat joins several arrays along a chosen axis; it does not add their elements. split or chunk groups them at specified boundaries. Every axis that is not being joined has to be compatible. chunk here means a block of an array, whereas a chunk in networking is a slice of bytes. Independent example: two heads of [2,3] each, joined along the feature axis, give [2,6]; joined along the position axis they would give [4,3], which already means something different.

Multi-head attention computes in different projection spaces and concatenates the results. Giving each head a fixed name such as "syntax head" or "fact head" does not provide a complete explanation. The original paper proposed an encoder–decoder architecture; a GPT-style causal decoder is organized differently, and their diagrams must not be conflated.[S008][S002]

A Transformer layer contains more than attention

Start with the objects and symbols used here
Norm, LayerNorm, RMSNorm: not a probability normalization
In a layer formula, Norm stands for a normalizing function. LayerNorm usually subtracts the mean over one token's features, divides by the standard deviation, then scales and shifts; RMSNorm usually does not subtract the mean and scales by the root mean square. Neither of them is softmax. Independent micro-example, ignoring the small positive ε that stabilizes the denominator and the learnable scaling: LayerNorm([1,3])=[-1,1]; RMSNorm([1,3])=[1/√5,3/√5].

Attention exchanges information across positions, the feed-forward network applies a nonlinear transformation at each position, residual connections help information and gradients propagate, and normalization controls internal scales. One teaching Pre-Norm block is:

H = X + Attention(Norm(X))
Y = H + MLP(Norm(H))
Start with the objects and symbols used here
MoE, experts and the router
MoE is a model structure that contains several sub-networks; the router selects or weights a few experts for the current token's representation. An expert is usually a numeric sub-network, not a chat agent given a prompt such as "math teacher". Independent example: with 4 experts and 2 chosen per token, one pass activates only 2 of the expert paths; the parameters and routing state that the model design requires still have to be stored.

This is not the full arrangement in the original 2017 paper. Modern models may also use different normalization, activations, positional encodings and MoE structures. After learning the components, still check the specific architecture of a real implementation.[S008][S016][S017]

Self-attention without an ordering signal struggles to distinguish permutations. The original method adds position representations to the input; RoPE rotates paired dimensions of Query/Key so that their dot products include relative position information. RoPE does not guarantee generalization to unlimited lengths; training and extension methods still constrain it.[S012]

From hidden states to the next token

The final hidden representation passes through an output projection to produce logits over the vocabulary, then a probability transformation and decoding select a token. Logits are not calibrated factual confidence. The autoregressive factorization is:

P(x₁,…,x_T) = ∏ P(x_t | x₁,…,x_(t−1))

The newly selected token joins the subsequent prefix, and the loop continues until normal completion, a tool call, the budget limit or an external interruption. A high-probability sentence only fits the conditional distribution; it does not guarantee factual truth. A nonexistent API may also sound plausible.[S034][S179]

During training, the target sequence is known, so losses at different positions can be computed in parallel, with a causal mask preventing a peek at the answers. In ordinary autoregressive inference, a later step depends on the token chosen at the previous one, creating a serial dependency. Thus, "Transformers can parallelize" does not mean "generate the entire answer unconditionally in one pass".[S009]

MHA, MQA, GQA and MoE

Start with the objects and symbols used here
MHA, MQA, GQA: how heads are shared
An attention head is one path that matches and then aggregates content. MHA usually gives every query head its own K/V head; MQA has several query heads share one group of K/V; GQA sits between them, sharing by group. These are structural choices, not a switch to be flipped at run time. Independent shape example: 8 query heads and 2 K/V heads, grouped evenly, means every 4 query heads share 1 group of K/V; the cache is accounted for by the number of K/V heads.

MHA usually provides separate KV for different query heads; MQA shares one KV group; GQA shares KV among groups of query heads. Fewer KV heads help cache size and bandwidth, but do not guarantee a proportional end-to-end speedup. MoE is sparsity at another level: a router chooses a few expert networks to process a token, rather than several chat agents holding a meeting. Total parameters and active parameters are also different quantities.[S013][S014]

Llama3, DeepSeek-V3 and Qwen3 provide different system cases. When reading reports, distinguish architecture, data, training, post-training and serving optimizations. Do not attribute overall performance to one component or treat historical technical reports as a current leaderboard.[S016][S017][S018]

From mechanisms back to engineering

Window capacity does not guarantee that every constraint is used. A model may ignore negation, confuse versions or follow a strong prior. For "default behavior must be preserved", turn the requirement into regression tests rather than merely repeating it in a long prompt. This is advice for applying the mechanism to engineering and must be verified on actual tasks.[S085][S088]

Self-check: does zero temperature eliminate hallucinations? No. It changes how output is selected, not the available evidence. Are GQA and multi-agent systems the same kind of thing? No. The former is inside the model, and the latter organizes execution outside it.

A 1.1 · The Transformer, illustrated

Related material: The Illustrated Transformer

The Illustrated Transformer explains encoders, decoders, attention and feed-forward networks through their structure. Track information sources and flows before the matrix details. The original architecture includes an encoder–decoder and cannot be treated directly as the complete diagram of every decoder-only product.

An embedding is only an initial representation, which later layers change based on context. Residuals preserve an information path, while feed-forward networks apply nonlinear transformations at each position. Attention is not the model's only computation, or database retrieval.

A 1.2 · The tokenization pipeline

Related material: The Tokenization Pipeline

A tokenization pipeline may include normalization, pretokenization, subword learning and special-token postprocessing. BPE progressively merges common fragments; other algorithms use different objectives. Tokenization cannot be reduced to splitting on spaces, nor can every model be assumed to lowercase text.

An ID maps to an embedding, but IDs themselves have no semantic ordering. Code spaces, line breaks, rare identifiers and byte encoding may affect length. Special tokens may also express boundaries, and arbitrary edits or deletions change the model's interpretation.

A 1.3 · Attention and the original Transformer architecture

Related material: Attention Is All You Need

The original Transformer organizes sequence processing with attention and includes scaled dot products, multiple heads, positional encoding, feed-forward networks and residuals. The core computation produces weights using Q and K, then combines V. Causal generation must also prevent future information from flowing into the current position.

QKᵀ/√d_k controls the scale of matching scores, and softmax normalizes over allowed positions. Multiple heads compute in different projection spaces, but each head cannot be permanently named after a human function. The original paper's task and today's coding agents operate at different levels.

A 1.4 · The Transformer annotated with code

Related material: The Annotated Transformer

The Annotated Transformer presents model structure beside its implementation, making it useful for moving from concepts to tensor operations. A historical tutorial's dependency versions do not guarantee compatibility with the current environment; this book focuses on algorithms and shapes rather than copying potentially outdated installation steps.

When reading code, trace how batch, sequence, hidden and head dimensions change, how masks broadcast, and how dimensions are restored after concatenation. Many errors come from transposition or mask direction, not from unfamiliarity with the word attention.

B 1.5 · Word vectors, illustrated

The Word2Vec tutorial explains learning continuous word vectors through context prediction. B 1.6 · Different forms of attention

Related material: Attention? Attention!

Attention has different scoring methods and visibility scopes. Self-attention usually computes among representations of the same sequence, while cross-attention connects representations from different sources; additive and dot-product attention also use different formulas.

Local or sparse scopes can change compute requirements and information paths, but restricted access may lose important relationships. Modern systems may combine different structures; one classic schematic is not the only implementation.

B 1.7 · Rotary position encoding, RoPE

Related material: RoFormer

RoPE encodes position through rotation so that dot products between Q and K include relative position relationships. It differs from adding position embeddings directly to input vectors; consult the model implementation for the precise application.

Two-dimensional rotation preserves length, but angular differences between positions affect their relative relationship. Higher dimensions can consist of multiple two-dimensional subspaces, with different frequencies expressing different scales. This mathematical mechanism is not perfect distance reasoning.

B 1.8 · Grouped-query attention

Related material: GQA

GQA shares KV among groups of query heads, between separate KV for each head and one KV group shared by every query. The paper also studies a training path for converting multi-head models. This is an internal model structure, not a grouping of agent tasks.

Fewer KV heads reduce cache size, but query heads and KV heads differ and cannot be interchanged in estimates. Actual speed also depends on feed-forward networks, kernels, bandwidth and scheduling; a cache ratio is not an overall speedup ratio.

B 1.12 · DeepSeek-V3: sparse-model engineering

Related material: DeepSeek-V3 Technical Report

Start with the objects and symbols used here
MLA: a learned low-dimensional K/V representation
MLA refers to a family of multi-head latent attention architectures. It organizes the content behind K/V jointly in a lower-dimensional latent representation and handles the positional part by design. It changes the model's representation and parameter structure; it is not just ZIPping an ordinary KV file. In c=xW_down, c is the latent vector for this computation and W_down the learned table of dimension-reducing coefficients; how it is later reconstructed or absorbed into a projection has to be explained for the specific architecture.

The DeepSeek-V3 report discusses designs such as MoE, MLA and training systems. MLA differs from conventional KV organization, reminding us that the standard cache formula is not universal across architectures. A multi-token prediction training objective also does not imply that multiple tokens can be output at deployment without verification.

Sparse experts separate total parameters from active computation, but communication and load still affect efficiency. Training cost, inference cost and model performance must be examined separately; the report's measurement bases cannot be mixed for a simple comparison.

C 1.14 · A panorama of LLM technology research

Related material: A Survey of Large Language Models

An LLM survey provides a knowledge map, collecting research on architecture, training, adaptation and evaluation. The cited works use different models, data and time periods; inclusion in a survey does not automatically give their conclusions one shared scope of use.

Start with the objects and symbols used here
RLHF, the reward model and the policy
RLHF refers broadly to processes that train behavior using human feedback. A reward model scores behavior such as an answer; the policy is the probability model that actually produces actions. Their jobs differ, and a high reward is not automatically factual correctness. Independent example: if the reward model prefers long answers, the policy may learn to write at length without being more accurate; the reward criterion therefore needs to be validated.

As you read, record each technique's layer, the problem it solves and the assumptions it needs. RAG changes evidence sources, RLHF changes training behavior, and KV cache changes computation reuse; these are not the same kind of prompt technique.
