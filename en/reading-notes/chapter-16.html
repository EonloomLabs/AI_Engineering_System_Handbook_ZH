In a training batch the input and the correct continuation are already given, so the prediction error can be computed for many positions together, while the causal mask still forbids peeking at the future. When reading a training formula, first separate the forward pass, the loss, the backward pass and the update; backward does not mean the parameters have already changed.

Essential mathematics and implementation basics

Vectors, matrices, conditional probability, logarithms, derivatives and the chain rule are entry points for understanding small language models. Deep-learning textbooks supply the basics, while CS336 and courses on implementation from scratch connect concepts to models. You need not finish all mathematics before experimenting, but should be able to explain the quantities in every formula.[S191][S005][S193]

Vectors represent features, matrices transform them, dot products calculate compatibility, softmax normalizes scores, and negative log likelihood penalizes low probability for the true target. These computational roles do not mean every dimension corresponds to a concept a person can name.

One gradient update

Original examples: y=wx+b, L=(y-t)^2. With x=2, t=5, w=1 and b=0, y=2 and L=9; the gradient is dL/dw=-12, dL/db=-6. Updating with learning rate 0.1 gives w=2.2 and b=0.6, making y exactly 5. This is a coincidence of these particular numbers, not a claim that one gradient-descent step always reaches the optimum.

Autodiff propagates gradients through the computation graph; it does not judge whether the loss objective is right. Calculating gradients differs from an optimizer updating parameters; inference usually does not need the gradient graph used in training.[S194]

Connect the full chain with a character model

An original experiment can build a character vocabulary from your own short text, construct input and right-shifted targets, train a small autoregressive model and then sample. Character-level modeling suits teaching and is not a complete replacement for modern subword tokenizers.

Token tensors are often B×T, becoming B×T×D after embedding; attention computes across sequence positions, and the output gives each position's vocabulary scores. The causal mask and right-shifted targets prevent looking at the answers. nanoGPT offers a concise implementation entry point; this book does not claim to have trained it or reproduced its results.[S192]

Data splitting and generalization

The training set updates parameters, the validation set selects configurations, and the test set offers relatively independent evaluation. Repeatedly inspecting the test set to change the model turns it into development data. Random splits of adjacent or near-duplicate content may leak information; consider splits by document, time or source.[S023][S005]

Original examples: training on an old README and testing on its new version may involve substantial overlap and cannot prove generalization to a new project. Getting a pipeline to run also does not establish understanding of target alignment and overfitting.[S001]

Five completion criteria

Identify tokenizer output; trace embedding and attention dimensions; work out softmax by hand; explain the loss; state why inference does not update weights. Then run controlled experiments: does removing the mask leak information, what happens when targets are shuffled, does a small dataset overfit, and does temperature change a distribution or verify facts?

The accompanying experiments need no API and help isolate mechanisms; they do not replace actual model evaluation. Basic knowledge ultimately serves engineering diagnosis: caching is not memory, compaction is not training, tool results are only new input, and a long window does not guarantee constraints hold.

Self-check: training loss falls but test performance worsens? Overfitting or a distribution difference is possible; this cannot directly be called greater intelligence. Can a small experiment prove a commercial agent's quality? No; it can explain only a local mechanism.

B 16.1 · From automatic differentiation to language models

Related material: Neural Networks Zero to Hero

Zero to Hero progresses from basic neural networks and automatic differentiation to language models, using implementation to understand computation graphs, training and generation. Its content is not an entire set of prerequisites that must be completed before using agents.

B 16.2 · A minimal GPT training system

Related material: nanoGPT

nanoGPT connects data, a GPT model, training and sampling in a relatively concise implementation. It suits source study, but this book does not claim to have downloaded or trained it or reproduced its performance.

Pin a version when reading, and trace input shapes, the causal mask, right-shifted targets and the generation loop. Training and inference code perform different work.

Start with the objects and symbols used here
Labels, teacher forcing and shift
A label is the correct target to compare against; next-token training lines each input position up with the token after it. Teacher forcing computes with the real prefix from the data rather than replacing it with what was just sampled. Independent example: for the full sequence [a,b,c,d] the input [a,b,c] can be paired with the labels [b,c,d]. When the interface already shifts them, do not shift them a second time outside it.

C 16.6 · Tensors, automatic differentiation and model training

Related material: PyTorch Documentation

PyTorch supports model implementation with tensors and automatic differentiation. Autodiff calculates gradients; the optimizer updates parameters. These are different actions, and inference usually need not save the same training graph.

The framework does not judge whether the loss expresses the right business objective or automatically prevent data leakage. Dimensions, targets and training/validation modes still need checks.
