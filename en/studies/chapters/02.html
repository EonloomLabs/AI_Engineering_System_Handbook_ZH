1. This book's implemented architecture differs from the original paper

Start with the objects and symbols used here
SwiGLU, Wg/Wu/Wd: two transformation paths, then combined
This is a gated feed-forward structure. Wg produces the path that goes through SiLU, Wu produces the other content path, the two are multiplied element by element, and Wd maps the result back to the original width. These Ws are three sets of parameters, not three agents. To read (SiLU(XWg)⊙XWu)Wd, compute XWg and XWu first, then SiLU, then ⊙, and finally multiply by Wd. Every position uses the same set of parameters independently.
Norm, LayerNorm, RMSNorm: not a probability normalization
In a layer formula, Norm stands for a normalizing function. LayerNorm usually subtracts the mean over one token's features, divides by the standard deviation, then scales and shifts; RMSNorm usually does not subtract the mean and scales by the root mean square. Neither of them is softmax. Independent micro-example, ignoring the small positive ε that stabilizes the denominator and the learnable scaling: LayerNorm([1,3])=[-1,1]; RMSNorm([1,3])=[1/√5,3/√5].
MHA, MQA, GQA: how heads are shared
An attention head is one path that matches and then aggregates content. MHA usually gives every query head its own K/V head; MQA has several query heads share one group of K/V; GQA sits between them, sharing by group. These are structural choices, not a switch to be flipped at run time. Independent shape example: 8 query heads and 2 K/V heads, grouped evenly, means every 4 query heads share 1 group of K/V; the cache is accounted for by the number of K/V heads.

The 2017 Transformer paper proposed an encoder–decoder architecture; this book's numerical experiment uses a modern-style decoder-only teaching model with pre-RMSNorm, RoPE, GQA and SwiGLU. The combination exposes common implementation boundaries; it does not mean any particular closed-source model uses exactly this configuration.[N07][N08][N09]

Let batch size be B, sequence length T, hidden width d, query heads h, KV heads g, and head width dh=d/h, with h divisible by g. The randomly initialized experiment uses d=16,h=4,g=2, with two layers in total. Small numbers let every shape be printed individually; they cannot evaluate large-model capability.

Start with the objects and symbols used here
Wq / W_Q: the query projection parameters
This is the parameter matrix that turns the input representation into the query, not the query itself. Under this book's right-multiplication convention, each input row has d numbers and Wq has d rows and d_k columns, so after Q=XWq each row has d_k numbers. The subscript q marks what it is for; it does not mean multiplying by another q. One Wq can handle many positions; each position gets its own q. F11 gives X, Wq and every multiply-add result.
Wout, LM head: the vocabulary scoring parameters
The parameter layer that turns the final hidden representation into a score for every vocabulary candidate. The input width is d, the vocabulary has Vocab entries, and the right-multiplied parameter shape is [d,Vocab]. Producing probabilities means normalizing these scores as well. Attention's Wo outputs hidden features; Wout outputs scores over vocabulary candidates. Both names contain "output", but what they output is different.

Checking shapes line by line matters more than reciting component names. For example, softmax over the head dimension can have a valid shape yet turn "which historical positions to read" into "competition among heads". Such an error may raise no exception while silently changing the model.

2. What actually flows inside a layer

Start with the objects and symbols used here
⊙: element-wise multiplication, not matrix multiplication
Elementwise multiplication multiplies the numbers at the same position once the shapes are aligned; it does not then sum along any dimension. Matrices written side by side in a formula, or @, usually mean matrix multiplication, and the two are not interchangeable. Independent micro-example: [1,2]⊙[3,4]=[3,8], whereas the dot product is 11. The ⊙ in a gated feed-forward network modulates one path with the other, feature by feature.
γ, β, ε: keep the parameters and the stabilizing constant apart
In the LayerNorm expression, γ is a row of learnable multiplicative coefficients and β a row of learnable additive ones; ε is a small positive number set by hand, placed in the term involving the denominator to avoid division by zero and similar problems. The mean μ and the variance σ² that are computed are in turn statistics of this data.γ=1 and β=0 usually mean that every feature uses 1 and 0; they are not the meaning of an input word. The β in DPO refers to a coefficient of the objective function, and the sense it has here does not carry over.

RMSNorm computes the root mean square over the final dimension: norm(x)=x/sqrt(mean(x²)+ε) ⊙ γ. It differs from LayerNorm, which subtracts the mean. A pre-normalization residual structure can be written as u=x+Attn(norm(x)), y=u+FFN(norm(u)). Residuals provide direct paths for information and gradients, but cannot simply be claimed to guarantee stable training at any depth.

Start with the objects and symbols used here
sigmoid: maps a single number into the range between 0 and 1
The function rule is sigmoid(x)=1/(1+exp(-x)). It computes number by number and does not require one row of results to sum to 1, so it cannot stand in directly for a softmax over several candidates. Independent micro-example: sigmoid(0)=0.5; computing two zeros separately gives [0.5,0.5], which is only a coincidence — for the input [1,1] the two terms already sum to more than 1.

This experiment writes the SwiGLU feed-forward structure as (silu(uWgate) ⊙ uWup) Wdown, where silu(a)=a×sigmoid(a). It independently transforms every position nonlinearly, while attention mixes across positions. A feed-forward layer is not accurately imagined as a static factual database that retrieves without computing; model behavior comes from all layers working together.

Attention scores are divided by√dh based on dot-product variance: with independent components of zero mean and unit variance, dot-product variance grows with dh. Scaling moderates scores near initialization. These assumptions do not strictly hold after real training, but the formula is not an arbitrary decoration.

3. Causal-mask semantics and negative controls

In a full forward pass, query i sees only key positions j≤i. Forbidden positions receive negative infinity, giving zero softmax weight. A test should change inputs after position k and assert outputs before k stay unchanged. Removing the causal mask should make the same test fail: a negative control establishes that the test can catch its target error.

A fully masked row is a special case. Applying "subtract the maximum" directly to an all-negative-infinity row produces−∞−(−∞) and NaN. This book's implementation explicitly rejects such input; production operators may define zero outputs or another convention, but callers must know the contract. Ordinary samples running successfully does not establish correct padding or empty-sample handling.

The mask for cached decoding has to be filled in by absolute position; the small triangle cannot simply be copied

4. Why RoPE brings position into relevance

For each component pair (a,b), position p has rotation angle pθ:

R(pθ)[a,b] = [a cos(pθ) − b sin(pθ), a sin(pθ) + b cos(pθ)]
(R(p)q)ᵀ(R(t)k) = qᵀR(t−p)k

The second equation follows from rotation matrices' orthogonality and angle addition, showing that rotated dot products can contain relative position differences. Different component pairs use different frequencies, distributing position signals across scales. The experiment checks that rotation preserves each pair's norm; norm preservation establishes only part of the rotation implementation's properties, not long-context extrapolation capability.[N09]

In cached inference, with existing prefix length P and new chunk length C, new chunk positions must be P…P+C−1. Resetting positions to zero at every call changes relative positions between new queries and old keys, so outputs remain wrong even when cache length and tensor shape are correct. wrong_offset=True Deliberately introduce this error; numerical tests should detect it.

RoPE extensions do not mean "increase the maximum-position parameter and obtain reliable long context". Position interpolation, frequency changes, training length and data all affect behavior. Use a model's supported configuration, then test tasks combining information over long ranges rather than merely checking whether long inputs are accepted.

The first two rows move both sides one step at once; the angle between them does not change, so the dot product does not change either. This is one intuitive sign of relative position entering the matching.

The old keys in the cache already carry their original positions. If a new token is reset to 0, that is not "merely renumbering": it changes the relative angle between the old and the new vectors.

A real implementation also has to distinguish position_ids, cache_position and the physical slot; a sliding cache moves storage slots, which does not mean the semantic positions are reset as well.

5. What the KV cache actually stores

Start with the objects and symbols used here
Query, Key, Value: three intermediate numeric representations
q is one row of query representation for the position receiving information; k is one row of matching representation offered by a readable position; v is one row of content representation that position contributes to the mix. Capital Q/K/V collect several rows into tables. They are computed from the input and the parameters, and they carry the separate jobs of scoring and of supplying content. One q dotted with two k gives two scores; softmax turns them into two shares; those shares multiply the two rows of v, and the results are added. Nothing here generates a search term, and nothing here picks an answer directly.

In a causal model, appending a new token does not change old positions' representations at any layer: old positions cannot see the future. Their projected K and V can therefore be saved, while new positions compute only their own Q, K and V and read the historical cache. It caches intermediate tensors for that layer, prefix and model parameters, not an input-independent knowledge base.

The mask for each layer's new chunk is not a simple C×C triangle, but C×(P+C): row i in the new chunk permits keys j≤P+i. An unaligned "upper-left triangle" hides old prefix positions that new tokens should see. Full-sequence, token-by-token and arbitrary-chunk inference should produce the same logits within tolerance.

Start with the objects and symbols used here
LoRA, low rank and r
LoRA represents part of a weight increment as the product of two smaller matrices instead of retraining the whole large matrix. r is the inner dimension, and it bounds the maximum rank of that product. Where sources use a row-vector or a column-vector convention, the left-right order of A and B can differ. Micro-example in the right-multiplication convention: with W[4,6], the increment A[4,2]B[2,6] is still [4,6]; r=2. A here is not the table of attention shares.

The experiment caches rotated K and originally projected V. Other architectures may cache different representations, so this assumption is not universal. Changes in model weights, LoRA adapters, template prefixes or position policies may invalidate existing caches; a cache hit requires matching computational state, not merely shared words in strings.

Engineering case · D01

Failure experiment: why is the uncached forward pass correct but incremental output distorted?

Fix the problem definition before changing the model

The symptom is a correct full forward pass on the same known sequence but divergent results after splitting it into historical cache+new tokens. Candidate causes include duplicate projection, inverted mask semantics, position offsets, repeated RoPE rotation, accidentally enabled dropout and numerical precision. Fix parameters, dtype and random paths first, then isolate variables one by one rather than immediately enlarging the model or loosening tolerance.

This experiment uses PyTorch2.10 CPU and explicitly runs no fused GPU kernels. The first check gives high-level MHA and SDPA the same projections and visibility; the second makes all scores equal so output reflects only the visible Key set; the third tests position rotation separately. Every check has a discriminating counterexample.[SDPA] [MHA]

Core observations

Cache P=3, 2 new queries and 5 total keys; V=1 through 5. The correct explicit table outputs 2.5 and 3, while the upper-left automatic causal table outputs 1 and 1.5. Visibility alone determines the numerical difference, without involving language capability. Testing only equal Query and Key lengths would hide the triangle-alignment error.

Why the diagnostic path works

Zeroing Q/K gives every valid Key the same weight, so the expected average can be calculated by hand; if the result is wrong, inspect the mask before projection parameters. Restore nonzero Q/K to test scaling and softmax, then real shapes to examine head mapping and cache layout. Restoring complexity gradually keeps each failure attributable.

How to read the changes in the figure

The proof runs forward from the first layer: the old positions cannot see the new d, so the old representations in the first layer are unchanged; the old inputs to the second layer are therefore unchanged too, and so it holds layer by layer.

The old Q was mainly used to compute the output at the old positions. Only the new output for d is required now, and no read needs to be issued with the old Q again, which is why K/V is usually cached and Q is not.

Changing the model parameters, the template or the old positions breaks the premise for reuse. "The same session" is not a mathematical condition for cache validity.

Do not conflate: with bidirectional attention an old position may see newly added content, so this causal-cache argument cannot be applied unconditionally.

6. What GQA reduces and what it does not

In MHA, each Q head usually has corresponding K and V heads; GQA lets a group of Q heads share one K and V head, while MQA is the extreme with only one KV head. Keeping h fixed while reducing g shrinks cache and K/V projection outputs; Q heads can still produce different attention distributions through different Q representations.[N08]

Approximate KV memory is 2×层数×批大小×序列长×KV头数×每头维度×每元素字节. A teaching assumption of 32 layers, 1 sequence of length 32768, 8 KV heads, width 128 per head and 2 bytes gives 4GiB; with 32 KV heads, it becomes 16GiB. This excludes paging metadata, alignment, fragmentation, temporary buffers and quantization scales, and is not actual usage by a service.

For readability, the code uses repeat to expand shared KV; high-performance implementations should avoid unnecessary copies. Naive tensor operations can offset the algorithm's conceptual memory savings, illustrating the gap between "understanding a paper" and "writing an effective engineering implementation".

7. Implementation acceptance

Start with the objects and symbols used here
Concat, split and chunk: joining and splitting
Concat joins several arrays along a chosen axis; it does not add their elements. split or chunk groups them at specified boundaries. Every axis that is not being joined has to be compatible. chunk here means a block of an array, whereas a chunk in networking is a slice of bytes. Independent example: two heads of [2,3] each, joined along the feature axis, give [2,6]; joined along the position axis they would give [4,3], which already means something different.

When reading Decoder.forward, locate normalization, projection, where RoPE is applied, the cache-concatenation axis, non-square masks, the softmax axis, head-combination order and feed-forward residuals. Each should have at least one invariance check or negative control.

Start with the objects and symbols used here
Dropout: the rule that randomly zeroes values during training
The common inverted dropout zeroes elements at random during training with drop probability p, and divides the kept ones by 1-p so that the expected scale is preserved. Evaluation mode usually turns this random operation off; the underlying function may require the caller to pass p=0 explicitly. Independent example: with p=0.5, a value of 2 comes out as 4 if it is kept in a given mask and as 0 if it is dropped. This is not training permanently deleting the corresponding model parameter.

Acceptance question: if full-sequence and cached outputs differ, what should be checked first? Check whether dropout is disabled, parameters match, and position offsets and masks align; then inspect dtype and numerical tolerance. Do not hide logic errors merely by widening tolerance. If error suddenly grows with length, also inspect position limits, cache truncation, padding and sliding-window rules. High-precision teaching results are only a baseline; low-precision kernels need separate definitions of acceptable error and final-task degradation.
