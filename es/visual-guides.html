Herramientas de lecturaAprox. 5.5 millares de caracteres

Partir de una entrada y seguir valores, mensajes, evidencia y estado de ejecución para ver cómo funciona el sistema.

Las entradas y condiciones de cada diagrama se explican siempre antes de él. Una optimización que afirma «conservar el mismo resultado» precisa qué conserva y bajo qué supuestos; una aproximada muestra qué cambia.

Se recomienda empezar por dos cadenas completas: Texto de entrada → primera predicción → siguiente ronda → EOS　Usuario → modelo → herramienta → incorporación del resultado
