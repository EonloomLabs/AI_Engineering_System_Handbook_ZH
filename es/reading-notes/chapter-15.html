Elegir primero el nivel correcto de intervención

RAG aporta evidencia externa, Memory conserva información entre tareas, Skills organiza métodos, el harness de ejecución gestiona la ejecución y Fine-tuning cambia el comportamiento mediante parámetros. Ante código reciente desconocido, priorizar la recuperación; ante errores de permisos, corregir el ejecutor; solo los sesgos de comportamiento estables podrían requerir entrenamiento.[S095][S113][S122][S172]

Ajustar necesita datos representativos y evaluación independiente, no solo pérdida o demostración. Conserva regresión de capacidades originales para no sobreajustar una tarea.

LoRA, QLoRA, AWQ y destilación

Conocer primero los objetos y símbolos de esta sección
LoRA, bajo rango y r
LoRA representa parte del incremento de los pesos mediante el producto de dos matrices menores, en lugar de volver a entrenar toda la matriz grande. r es la dimensión intermedia y limita el rango máximo de ese producto. El orden de A y B puede variar entre fuentes que adoptan convenciones de vectores fila o columna. Microejemplo con convención de multiplicación por la derecha: W[4,6], el incremento A[4,2]B[2,6] sigue siendo [4,6]; r=2. Aquí A no es la tabla de proporciones de atención.

LoRA congela los pesos base y usa incrementos de rango bajo W'=W+BA Entrenamiento. Cálculo original: una matriz 1024×1024 tiene 1,048,576 parámetros; las dos matrices incrementales de rango r=8 suman 16,384 parámetros. Esto solo describe el incremento entrenable de esa matriz, sin implicar una reducción proporcional de toda la memoria de GPU del modelo.[S174]

QLoRA combina un modelo base cuantizado con adaptación de rango bajo; AWQ utiliza información de activaciones para orientar la cuantización de pesos con pocos bits. Cuantizar los pesos no significa que todo el cálculo use los mismos pocos bits: la velocidad sigue dependiendo de kernels y hardware. La destilación entrena al alumno con señales del profesor, sin garantizar que copie todas sus capacidades. PEFT ofrece implementaciones, pero no sustituye la gobernanza de datos.[S175][S176][S177][S178]

Hechos, alucinaciones y calibración

TruthfulQA estudia la imitación de errores conceptuales comunes; la investigación sobre autoconocimiento del modelo observa capacidades de autoevaluación bajo ciertas condiciones, sin justificar tratar cualquier confianza verbal como probabilidad exacta. Probabilidad de generación, exactitud factual y calibración son conceptos distintos.[S179][S180]

Ejemplo original: diez respuestas declaran 0.9 y solo cinco son correctas, lo que muestra exceso de confianza en esta muestra, aunque es demasiado pequeña para estimar con precisión la calibración global. Las vías fiables incluyen obtener evidencia, expresar lo desconocido, comprobar citas, calcular y probar; ninguna garantiza por sí sola corrección absoluta.

RAG adaptativo y correctivo

Self-RAG estudia cómo aprender cuándo recuperar y evaluar la generación, más allá de añadir «autocomprobación» a un prompt ordinario; CRAG estudia cómo corregir evidencia insuficiente. Ni los documentos puente para recuperar ni la autoevaluación constituyen hechos demostrados.[S181][S182]

El flujo original clasifica la evidencia como suficiente, contradictoria o insuficiente: si falta, busca más; si contradice, comprueba fuentes y tiempos; si basta, genera conclusiones con referencias. No debe buscar indefinidamente para evitar decidir ni tratar documentos hipotéticos como evidencia original.

Ciclo de observación-acción de Computer Use

La entrada visual es solo una capacidad. Un GUI Agent también necesita capturas de pantalla, ejecución de acciones, nuevas observaciones y verificación de estado. Que el modelo produzca coordenadas de clic no significa que la operación haya funcionado; la resolución, el escalado, las ventanas emergentes y los cambios de página afectan a la localización.[S183][S184]

Ciclo original: ver la interfaz actual → determinar el objetivo → validar la autorización → ejecutar → volver a observar → verificar el estado de negocio. Una API estable suele facilitar el control exacto; si no hay una interfaz estructurada o se necesita verificar la interfaz real, GUI sigue teniendo valor.

SeeClick estudia la localización en interfaces y OSWorld evalúa tareas reales de escritorio. Acertar el botón «Guardar» no significa guardar con éxito: puede fallar por campos obligatorios vacíos. El ejecutor integrado debe verificar el estado real, además de coordenadas o declaraciones del modelo.[S185][S186][S187]

Límites de la interpretabilidad mecanicista

Conocer primero los objetos y símbolos de esta sección
SAE, activaciones y características interpretables
SAE es un autoencoder disperso que reconstruye activaciones del modelo combinando pocas características activas. Una activación es un valor intermedio de este cálculo, no un registro completo de razonamiento en lenguaje natural. Reconstruir con éxito no demuestra automáticamente que una característica tenga un significado causal único.
