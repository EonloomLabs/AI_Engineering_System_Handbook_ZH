Cómo reproducir

Leer no requiere dependencias. Los experimentos nuevos necesitan Python, PyTorch y pytest, cuyas versiones están en el registro. Con otras versiones, lee primero los fallos; aflojar aserciones no equivale a reparar.

cd AI_Systems_Engineering_Textbook_ZH/engineering/labs
python run.py

El programa solo crea archivos, SQLite, symlink y repositorios Git temporales. El experimento termina deliberadamente su subproceso, no el principal. Windows puede diferir en permisos de enlaces y disponibilidad Git; no se verificó en Windows ni macOS.

def online_attention(scores, values, block_size):
    # One row, no mask: each block is incorporated using the CURRENT running max.
    m = -math.inf; denominator = 0.; numerator = [0.]*len(values[0])

"""Two independent databases model an executor and a downstream effect store.
A deliberate os._exit occurs ONLY inside the supplied temporary directory.
"""
import json, os, sqlite3, sys
from pathlib import Path

def main():
    root=Path(sys.argv[1]).resolve(); mode=sys.argv[2]; phase=sys.argv[3]
    if mode not in {'unsafe','keyed'} or phase not in {'crash','resume'}:
        raise ValueError('invalid mode')
