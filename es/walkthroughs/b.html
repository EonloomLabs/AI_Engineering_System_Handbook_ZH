JSON: texto estructurado, no una acción ejecutada
JSON es un formato de texto que representa datos mediante objetos, matrices, cadenas, números y otros elementos. Los objetos entre llaves asocian nombres de campos con valores; las matrices entre corchetes conservan el orden de los elementos. Analizar JSON solo produce datos y no ejecuta automáticamente los nombres de herramientas que contiene. Ejemplo independiente: {"path":"a.py","limit":3} tiene dos campos; "3" es cadena y 3 es número; Schema puede exigir uno de ellos.

Sigue una trayectoria didáctica de protocolo diseñada por el autor, no una sesión real extraída de un LLM comercial. La estructura de herramientas es simplificada: Harness Formato propio, sin exigir coincidencia con ningún proveedor de JSON Los campos son idénticos. Patch, canales de imagen y proyección visual
Un patch de imagen es un pequeño bloque recortado y RGB son sus 3 canales rojo, verde y azul; en ingeniería de software, patch significa parche de código, con el mismo nombre. Un bloque de imagen aplanado puede convertirse en vector mediante una transformación aprendible; no consulta un vocabulario textual. B.2｜Llamada al modelo M1: por qué la entrada debe incluir el Schema de herramientas

Conocer primero los objetos y símbolos de esta sección
OAuth, scope y autorización
En autorización, OAuth permite a una aplicación obtener credenciales de acceso según el permiso concedido; scope declara una clase de ámbito de acceso, pero el servicio de recursos aún debe comprobar los permisos concretos. En memoria o tareas, scope también puede indicar solo el ámbito de aplicación y no debe confundirse con credenciales de inicio de sesión.
