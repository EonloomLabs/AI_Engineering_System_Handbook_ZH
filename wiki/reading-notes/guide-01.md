## 从“输入一句话”到“网络中的矩阵”

本篇对应《图解Transformer》的主题，用本书自编案例建立直觉，不是原文逐句翻译。先把三个层次分开：字符串是人类输入，Token ID是离散符号，隐藏向量是网络计算使用的表示。向量维度没有预先规定的中文释义，不能把它想成一个存满事实的表格。[[S006]](sources.md#S006)[[S007]](sources.md#S007)

假设教学Tokenizer把“检查路径过滤”分成三个Token，ID是7、12、3。真实Tokenizer未必如此切分，这里只为了追踪流程。查Embedding矩阵后得到三个向量，组成`3×d`矩阵。之后每层根据位置、上下文关系和非线性变换更新表示。


<span id="g01-section-2"></span>


## 为什么“同一个词”会因上下文改变

代码里的`root`可以是目录根、树根，也可以是某个对象名。初始词向量提供学习到的统计起点；上下文中的函数调用、注释与类型线索影响后续表示。网络不是先查一个“root唯一意思”再固定使用，而是在多层计算中形成适合当前输入的表示。[[S010]](sources.md#S010)[[S008]](sources.md#S008)

但表示能消歧，不等于模型已经执行语言解析器。真实代码中`root`绑定哪个变量、函数是否被调用，仍可能需要LSP、源码和运行证据。这说明底层能力与工程工具是互补关系。

### 一次前向中，哪些步骤混合位置，哪些只混合特征

**本例条件：**本图只追踪单样本、3个Token、每位置4个特征的形状。采用一个教学Pre-Norm层，省略bias与dropout；不是所有Transformer的固定排列。

位置轴T
:   有几处Token。

特征轴d
:   每处有几个数。

残差
:   把同形状分支结果加回主路。

一次前向中，哪些步骤混合位置，哪些只混合特征

| 运算 | 形状变化 | 混合发生在哪里 |
| --- | --- | --- |
| 输入X | [3,4] | 每行=一个位置 |
| Q/K/V投影 | [3,4]×[4,2]→[3,2] | 只重组同一行特征 |
| 匹配QKᵀ | [3,2]×[2,3]→[3,3] | 每格=一个查询对一个Key |
| 权重乘V | [3,3]×[3,2]→[3,2] | 沿可见位置混合信息 |
| 输出投影与残差 | [3,2]×[2,4] + X→[3,4] | 回到主路宽度 |
| FFN | [3,4]→[3,8]→[3,4] | 各位置使用同一组参数 |

各行是独立对象或条件的对照，不暗示上一行的结果自动进入下一行。

#### 怎样把图中的变化读明白

沿着表第二列检查相邻操作能否相乘，再读第三列：很多投影都没有跨Token交换信息。

真正把其他位置的信息搬进来的是权重乘V；矩阵乘法只是统一的计算工具，不同轴上的相乘有不同含义。

残差相加要求两边形状一致。扩宽到8是FFN的中间宽度，不能直接和4维主路相加。

**不要混淆：**若把[3,3]权重误当3个词表候选，程序也许仍可做softmax，但解释已经错了：这里的列是输入位置，不是输出词表。

机制依据：[[TR]](../sources.md#src-TR) [[F-TENSOR]](../sources.md#src-F-TENSOR)。本例数字和宿主场景为明确给定的教学设定，不是商业模型输出或生产性能测量。

## 一个完整层怎样工作

注意力让当前位置从其他可见位置组合信息；前馈网络对每个位置做非线性变换；残差提供跨子层的信息通路；归一化处理数值尺度。不同模型的顺序与具体组件可能不同，不能用原始2017年结构图描述所有现代模型。[[S008]](sources.md#S008)[[S009]](sources.md#S009)

教学结构可以写为：

```
输入表示 X
  → 注意力变换 + 残差
  → 前馈变换 + 残差
  → 下一层表示
```

原始Transformer包含编码器和解码器。编码器可以形成源序列表示，解码器结合已生成前缀与源表示继续生成。GPT类Decoder-only模型则以因果前缀生成作为主要结构。理解两者共同组件，同时保留结构差异。[[S002]](sources.md#S002)[[S008]](sources.md#S008)


<span id="g01-section-4"></span>


## 为什么需要位置与因果限制

“排除A，保留B”与“保留A，排除B”使用相近词汇，但顺序改变含义。位置编码让网络获得顺序信息；因果掩码限制生成位置不能读取未来答案。位置编码不是长期记忆，掩码也不是用户权限控制，它们发生在模型内部计算层。

训练时，目标序列已知，因此可以并行计算多个位置的预测损失；生成时，下一个Token依赖前一个已选结果，通常存在串行依赖。不要把“Transformer可以并行”误解为“所有回答都是一次无依赖生成”。[[S008]](sources.md#S008)


<span id="g01-section-5"></span>


## 用一个反例检查理解

模型看到“测试通过”四个字，不代表测试真的运行过。网络能处理这段文本，却不知道它是工具事实、用户陈述还是模型猜测，除非输入与训练行为帮助区分。工程系统必须保留来源和真实状态。

先认识这里的对象与符号

[Wq / W\_Q：查询投影参数](../concepts.md#concept-q-projection)
:   这是把输入表示变为Query的参数矩阵，不是Query本身。按本书右乘约定，输入每行d个数、Wq有d行d\_k列，Q=XWq后每行有d\_k个数。下标q表示用途，不表示再乘一个q。同一Wq可处理多个位置；每个位置得到自己的q。F11给出X、Wq和每个乘加结果。

[Wk / W\_K：键投影参数](../concepts.md#concept-k-projection)
:   这是生成Key表示的模型参数表。K=XWk中的X来自当前注意力输入，K是这次算出的结果；Wk不是保存文档关键词或密钥的表。Q与K每行宽度要相同，才能做点积。在F11，x₁=[1,-1]乘Wk得到k₁=[0,1]。不是把原来的Token ID拿来当Key。

[Wv / W\_V：值投影参数](../concepts.md#concept-v-projection)
:   这是从输入生成Value内容向量的模型参数表。V=XWv之后，Attention按读取份额混合V的各行。Value的宽度d\_v可与Query/Key宽度d\_k不同；它不是最终词表答案。F11中同一x₁=[1,-1]乘Wv得到v₁=[0,20]，再参与加权求和。

[Query、Key、Value：三种中间数值表示](../concepts.md#concept-qkv)
:   q是接收信息的一行查询表示；k是可读位置提供的一行匹配表示；v是该位置供混合的一行内容表示。大写Q/K/V把多行收集成表。它们由输入与参数计算得到，分别承担打分与提供内容的职责。某个q与两个k点积得到两个分数；softmax得到两个份额；这些份额分别乘两行v，再相加。这里不生成搜索词，也不直接选答案。

[Wo / W\_O：注意力输出投影](../concepts.md#concept-wo)
:   把各注意力头输出拼接后，再转换成主网络需要宽度的参数矩阵。它仍是一张系数表，不是softmax的份额，也不是词表输出头Wout。若两个头各输出2个数，拼接宽度4；右乘形状[4,6]的Wo，可得到6个数以匹配残差宽度。此为独立形状例。

[I：单位矩阵](../concepts.md#concept-identity)
:   I在矩阵公式里通常是单位矩阵：对角线为1，其他位置为0。尺寸合适时，向量或矩阵乘I保持数值不变。Wq=Wk=I是人为选择的特例，不能推断真实模型的投影都相同。独立微例：I=[[1,0],[0,1]]，[3,-2]I=[3,-2]。这里I不是字母i表示的位置下标。

[Norm、LayerNorm、RMSNorm：不是概率归一化](../concepts.md#concept-norm)
:   Norm在层公式中表示一个规范化函数。LayerNorm通常按一个Token的特征减均值、除标准差，再缩放平移；RMSNorm通常不减均值，按均方根缩放。它们不等于softmax。独立微例，忽略稳定分母用的小正数ε与可学缩放：LayerNorm([1,3])=[-1,1]；RMSNorm([1,3])=[1/√5,3/√5]。

[γ、β、ε：参数与稳定常数要分开](../concepts.md#concept-norm-params)
:   在LayerNorm式子中，γ是一排可学习乘法系数，β是一排可学习加法系数；ε是人为设置的小正数，放在分母相关项中避免除零等问题。计算得到的均值μ、方差σ²又是本次数据的统计量。γ=1、β=0常表示每个特征都用1和0，不是一份输入词义。DPO里的β另指目标函数系数，不能套用这里的意思。

[pre-norm / post-norm：归一化放在何处](../concepts.md#concept-prenorm)
:   pre-norm是先规范化再进入子层，残差从原输入直接相加；post-norm是子层结果与原输入相加之后再规范化。这描述运算顺序，不是训练前后两个阶段。独立结构对照：x+F(Norm(x)) 与 Norm(x+F(x))一般不相等。F代表这里被包裹的子层函数。

### 一个两位置单层Decoder，从输入一直算到词表概率

**输入与条件。**采用教学pre-norm Decoder：X=`[[1,0],[0,2]]`；LayerNorm的ε=1e−5，γ=1、β=0；Wq=Wk=Wv=Wo=I；因果注意力；FFN(z)=0.5×ReLU(z)；最后再LayerNorm并乘词表头 `[[1,0,-1],[0,1,0.5]]`。不使用RoPE和bias。


<span id="mechanism-original-worked-G01"></span>


| 步骤与对象 | 内部动作 | 中间结果 / 新状态 |
| --- | --- | --- |
| 1输入归一化 | 逐行Norm，不跨位置 | 约 `[[0.999980,−0.999980],[−0.999995,0.999995]]`。 |
| 2生成Q/K/V | 本例投影是单位矩阵 | 三者都等于归一化输入；这是为方便计算而选的特例。 |
| 3算因果注意力 | 第1位置只能看自己，第2位置可看两处 | 第2行权重约 `[0.055810,0.944190]`，加权输出约 `[−0.888377,0.888377]`。 |
| 4第一次残差 | 把注意力输出加回原X | 第2位置变 `[−0.888377,2.888377]`。 |
| 5Norm与FFN | 第2位置归一化约 `[−0.999999,0.999999]` | ReLU与0.5缩放后约 `[0,0.499999]`，再加残差得 `[−0.888377,3.388376]`。 |
| 6生成分数 | 最后Norm后乘词表头 | logits约 `[−0.999999,0.999999,1.499998]`，概率约 `[0.048611,0.359188,0.592201]`。 |

**把过程连起来。**模型内部每一个“层名”都对应一份实际新数组。词表概率出现在最后投影之后，而不是Attention权重直接变成词。

**边界与反例。**全部数值来自随包程序同一条前向链，展示值经舍入；这是未训练微型结构，不是任何商业模型的架构或输出。
