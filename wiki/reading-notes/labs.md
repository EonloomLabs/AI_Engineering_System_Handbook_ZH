# 10个离线机制实验

Python 3.10及以上，仅标准库；无需API、账号或网络。

全部实验使用人工数据或模拟环境，不访问真实用户资料。本包生成时已运行10个实验自检并全部通过。它们验证教材示例，不代表生产审计或任何产品基准成绩。


<span id="section-1"></span>


## 运行方式

先解压压缩包，在包含index.html的目录打开终端：

```
python3 reading-notes/experiments/run_all.py
```

也可以单独运行任一脚本。每个本地实验页面提供解释、完整源码与配套运行记录。

## [01 · 教学 BPE：字符怎样合并成 Token](lab-01.md)

观察一组简单语料如何决定字符对合并。训练规则与应用规则分开，保留原文本可逆。例子刻意不实现真实模型的字节编码、特殊Token和预处理。

先运行默认样例，再改变语料或合并次数。相同文本可能得到不同教学Token数，说明计数依赖分词器。不要把结果用于商业模型计费。
