## 涨了10个百分点，为什么还不能急着下结论？

一次实验怎样区别真实改进与偶然波动？

像给同一组题换两种解法：同题对照能减少题目难度不同带来的干扰。统计方法帮助表达不确定性，不会自动告诉你退化是否可接受、成本是否值得。实际决策还要回到任务类型、失误严重性和重复表现。

**配对**同一任务同时有新旧方案结果。

**百分点**两个百分率直接相减，如70%−60%=10个百分点。

**随机波动**在相同条件下多次运行也可能有不同结果。

**输入与适用条件：**构造的20题配对表：10都成、4新成旧败、2旧成新败、4都败。不把它当真实模型胜率。

## 概率与一次观察不是同一个数

真实成功概率可以理解为在给定任务分布和执行条件下长期重复的性质；某次测了20题得18题，是**样本估计**。样本越少，结果越容易因碰巧选到题或采样差异而波动。

**关键区别：**差异可能来自抽样波动或任务构成；要看配对任务和重复运行。

**容易误解：**不应只报两列总分就宣布因果收益。

**随机变量**是结果随试验变化的量，例如一次任务成功记1、失败记0。**期望**是按概率加权的平均；**方差**描述围绕平均的波动。F14已用普通数字算过方差，这里把它用于随机结果。

## 为什么重复同一题也会不同

模型采样、服务环境、工具返回时间、检索数据变化和并发，都可能影响结果。固定随机种子只能控制某些随机来源，不能自动固定所有计算与环境。

为什么重复同一题也会不同：逐项辨别

|  |  |
| --- | --- |
| 对象一 | 概率模型预期 |
| 对象二 | 一次实际观测 |
| 对象三 | 重复运行分布 |

**关键区别：**概率是对可能结果的描述，一次结果不能完全代表稳定能力。

**容易误解：**不要把单次成功当成必然成功。

所以比较A/B策略时，尽量让它们面对相同任务、版本与资源，记录多次尝试，而不是一次A今天跑、一次B下周跑后直接归因。

## 配对比较比只看两列总分更有信息

假设同20个任务，A成功15个，B成功17个。仅看总分是提高10个百分点。还要看：哪些A失败B成功，哪些A成功B失败，失败严重程度是否不同。

**关键区别：**即使输入相同，模型抽样、工具网络、环境竞争也可能导致结果差异。

**容易误解：**公平对比应尽量控制模型、工具和任务条件。

若B新增成功4题，同时退化2题，净增2题；这与只在两个明确修复任务上提升、其他完全不变的风险结构不同。**配对差值**以同一任务的两个结果比较，能降低部分任务难度差异的干扰。

## 同样的提升数字可能来自不同原因

把容易任务换多一些，整体成功率就可能提高，即使每类能力没变。把超时失败都删除，也会让结果显得更好。保留原任务集、错误分类和逐题结果；模型、Prompt、工具和环境尽量一次只改一项。小样本无法支撑很精细的排序，不确定性不是失败，而是当前证据的边界。

## 标准误差怎样理解

先认识这里的对象与符号

[二项、标准误差与Wilson区间](../concepts.html#concept-stats)
:   二项模型常用于固定次数独立成功/失败试验；标准误差描述估计量的波动尺度；Wilson是一种比例区间构造。McNemar关注配对分类结果中两种方向的不一致。样本依赖、任务难度混合或挑选题目会改变可解释范围；统计公式不是“成绩提高必定来自这个改动”的证据。

在独立同分布的简单二项设定下，成功率估计的标准误差近似`√[p(1−p)/n]`。p是成功概率或其估计，n是尝试数。n变大，误差规模通常变小。

标准误差怎样理解：逐项辨别

|  |  |
| --- | --- |
| 方案／对象 A | 旧版与新版分别总分 |
| 方案／对象 B | 同一任务配对结果 |
| 方案／对象 C | 看谁在哪些题上变好变坏 |

**关键区别：**配对比较保留“同一道题”的变化，比仅看两列平均更能定位回归。

**容易误解：**旧版对一组任务、新版对另一组任务不适合作因果比较。

逐格算清：配对评测：总分只差2题，底下可能有不同的输赢分布

同一批任务中的配对输赢分布双方都成功 13题A独赢 2题B独赢 4题双方都失败 1题A：13+2=15 / 20；B：13+4=17 / 20；净改善2题

步骤 1同一20题中，A和B都成功13题。

步骤 2A独自成功2题；B独自成功4题。

步骤 3双方都失败1题；合计13+2+4+1=20。

步骤 4A成功15题，B成功17题；净增2题同时退化2题。

同一批20个任务，B新增成功4题、又退化2题。只报告成功率从75%到85%，会掩盖回归风险。

数值除特别标注外来自本章已明确设定的教学条件；示意图表达算法结构，不代表商业模型参数或实时GPU执行速度。

比如p约0.5、n=100，标准误差约0.05。这不是“真实值一定在±5%”，更不是最终置信区间的完整计算，只是波动尺度的近似。样本小、成功率接近边界或任务相关时，要更合适的方法。

## 置信区间不是“模型有95%自信”

**置信区间**是按特定统计程序，从样本构造参数范围。95%描述该程序在满足前提的重复抽样中覆盖真实参数的长期比例，不能直接改写成“这次固定区间里参数有95%概率”。

**关键区别：**样本越少、结果波动越大，均值的不确定性往往越高。

**容易误解：**标准误差不是每条样本本身的标准差。

**Bootstrap（自助重采样）**从已有样本中有放回抽样，多次重新计算指标以估计波动。配对比较应一起抽取同一任务的A/B结果，不能拆散配对关系。它不能凭空弥补原样本完全不代表业务的问题。

## LLM-as-a-Judge为什么要校验

**模型评分器**可以评价开放式回答，但可能受答案长度、位置顺序、措辞风格及自身错误影响。两个答案交换左右位置后评分变化，就提示位置偏差。

应提供明确标准、校准少量人工判例、随机化顺序并检查关键类别。对可执行任务，真实测试和业务结果通常比单纯让模型看文字打分更直接。

## 效果大小与显著性不是一回事

大量样本可能把非常小的差异测得显著，但工程收益仍不足以支付复杂度；反之，高风险故障一次被明确修复，即使样本少，也值得采取针对性措施，而不应等待漂亮总分。

把统计不确定性、业务重要性、成本、回归和可解释原因放在一起判断。结论应是“在这些条件下，证据支持到哪里”，不是“新版本必然更强”。

### 同样净增4个成功，为什么还不能确定优化可靠

**输入与条件。**对同一组20个任务比较A/B：两者都成功10个、都失败2个，只有B成功6个、只有A成功2个。

| 步骤与对象 | 内部动作 | 中间结果 / 新状态 |
| --- | --- | --- |
| 1算A | 共同成功10+仅A成功2 | 12/20=60%。 |
| 2算B | 共同成功10+仅B成功6 | 16/20=80%。 |
| 3看配对变化 | 8个结果不同的任务里B赢6、输2 | 净增4，但样本仍小。 |
| 4做精确检验 | 零假设下8个变化各以1/2偏向一边 | 双侧二项概率约0.289063，并不足以在0.05阈值拒绝零假设。 |
| 5继续检查 | 按失败类别和任务难度看变化 | 保留个案与运行条件，不能只写“提升20%”。 |

**把过程连起来。**观察到较大涨幅不等于已经排除随机变化；同时“不显著”也不等于证明两者相同。

**边界与反例。**这是构造的配对数据；检验依赖任务配对等设计条件。所示差值为20个百分点。
