## 后训练改变行为，奖励不是事实裁判

既然模型会接下一Token，为什么还要SFT、偏好训练？

“能续写文本”不等于“能按用户意图回答”。监督微调提供示范回答，偏好训练比较候选行为；奖励只是一个被设计出来的评价信号。模型可能学到让评分变高的方式，因此还要独立检验真实性、任务完成和风险，而不能把奖励上升等同所有能力提升。

**SFT**用示范输入与目标回答继续监督训练。

**策略**模型在给定上下文下选择输出的概率规则。

**参考模型**用来衡量相对变化的冻结基线。

**KL**比较两个分布差异的一种量，不等于字面编辑距离。

**输入与适用条件：**本图仅展示偏好训练的数据关系，不把候选A/B标为真实产品测评；RLHF与DPO的具体目标区别保留在正文。

## 同一个“更好”，至少有三种含义

语言预训练常学习文本里什么Token接着出现；**监督微调SFT**用任务示例教模型如何回答；**偏好或奖励优化**比较哪些行为更符合给定目标。这些目标可能关联，但不是同一个损失。


<span id="fdiag-19-01"></span>


同一个“更好”，至少有三种含义：逐项辨别

|  |  |
| --- | --- |
| 对象一 | 正确性：是否满足事实 |
| 对象二 | 偏好：两个回答哪个好 |
| 对象三 | 奖励：训练信号的分数 |

**关键区别：**对齐方法常利用人类或AI偏好，但偏好高分不是事实真值保证。

**容易误解：**不能把奖励模型当成外部事实校验器。

一份回答更受评分者喜欢，可能因为更清楚，也可能因为更讨好。评分与事实正确若不一致，优化评分不能自动保证真实能力。

## 先固定一条不会变的主线

贯通模型只演示下一Token监督训练。真实LLM常先在大量文本上学条件分布，再继续进行指令或偏好相关训练。阶段不同，仍然需要前向、目标函数、梯度和参数更新；不能只把“喂更多Prompt”当作后训练。

预训练通常学习广泛语料中的预测规律；监督微调用期望回答示范希望模型怎样响应；偏好方法比较不同回答或使用奖励信号，使某些行为更容易出现。它们的训练数据、损失和采样方式不同。

适用边界：贯通模型只执行随包配置中的结构；本节对后训练或现代结构的说明依据[对应原始论文与官方接口资料](../reference/model-sources.md)，不代表本地训练已经实现这些扩展。

## SFT到底怎样处理问题与回答

独立示意序列：`BOS 用户：算1+1 助手：2 EOS`。可以只对助手回答部分的目标算loss，而把用户部分作为条件。**不算用户部分loss，不等于把用户输入遮掉**：助手位置仍需读取问题。loss mask控制评分，attention mask控制可见范围，两张表职责不同。

贯通模型全体十个位置都算loss，没有偷偷把它称作只训练回答的SFT。迁到真实聊天模板时还要核对角色标记、轮次边界、停止符号以及标签shift是否由框架负责。

适用边界：贯通模型只执行随包配置中的结构；本节对后训练或现代结构的说明依据[对应原始论文与官方接口资料](../reference/model-sources.md)，不代表本地训练已经实现这些扩展。

## DPO比较的不是两个答案概率的裸大小

DPO使用相同提示下的优选回答y⁺和较差回答y⁻，并相对一份参考策略比较对数概率差。定义：

```
a = [log πθ(y⁺|x) − log πref(y⁺|x)]
  − [log πθ(y⁻|x) − log πref(y⁻|x)]
L_DPO = −log sigmoid(βa)
```

π表示对完整回答的条件概率，通常通过回答各Token对数概率相加得到；β是损失设置，不是Adam的β1/β2。sigmoid是 `1/(1+exp(−u))`，不是多候选softmax。

独立数值对照：参考模型给优选、较差回答的概率分别0.2、0.4；当前模型分别0.3、0.3，则 `a=ln(0.3/0.2)−ln(0.3/0.4)=ln2`。β=1时 sigmoid(a)=2/3，loss=−ln(2/3)≈0.405465。当前两答案概率相等，并不意味着相对参考没有改善。

偏好目标额外需要哪些对象

| 步骤 / 对象 | 本步实际变化 |
| --- | --- |
| 相同提示x | 把优选回答和较差回答放在可比较的条件下。 |
| 两套概率 | 当前模型πθ与参考模型πref分别评价回答。 |
| 相对差值 | 计算两个回答相对参考的对数概率提升，再比较差值。 |
| 更新当前参数 | 由偏好损失回传到θ；参考模型通常不随同一优化步骤更新。 |

数值为独立教学设置，不来自贯通模型的两句训练结果。

适用边界：贯通模型只执行随包配置中的结构；本节对后训练或现代结构的说明依据[对应原始论文与官方接口资料](../reference/model-sources.md)，不代表本地训练已经实现这些扩展。

## RLHF与DPO为什么不能只按一个名称互换

常见RLHF流程可能包括奖励模型、策略采样、优势估计、KL约束和策略优化；DPO用偏好对构造直接优化目标，省去某些显式在线RL环节。不同方法不等于“让模型长篇解释就会更聪明”，也不能用一篇论文的结果保证任意工程任务改善。

推理模型的额外思考Token是推理时计算预算的一种用法；训练这种能力可能用强化学习等方法。**训练能力的过程**与**部署时消耗更多推理Token的过程**必须区分。

适用边界：贯通模型只执行随包配置中的结构；本节对后训练或现代结构的说明依据[对应原始论文与官方接口资料](../reference/model-sources.md)，不代表本地训练已经实现这些扩展。

## LoRA究竟训练了哪一部分

设冻结基础权重W[4,4]，用A[4,r]、B[r,4]表示增量ΔW=AB。前向使用 `XW+s(XA)B`；训练只更新选中的A/B等参数，W仍参与前向但不求或不应用其更新。

r=1时新增8个数，不是把W的16个数从系统里删除。节省的是所选更新参数及其相关梯度/优化器状态；基础权重和激活仍需要。初始若B=0，A的初次梯度可能为0，B仍可先获得梯度；不能因此立即判为实现错误。

适用边界：贯通模型只执行随包配置中的结构；本节对后训练或现代结构的说明依据[对应原始论文与官方接口资料](../reference/model-sources.md)，不代表本地训练已经实现这些扩展。

## 奖励、策略、轨迹不要一起背缩写

**策略policy**是给定当前条件如何选择动作的概率规则。对语言模型，动作可以是下一个Token；对一次完整工具任务，许多动作构成**轨迹trajectory**。


<span id="fdiag-19-02"></span>


**关键区别：**比较必须有共同的上下文条件，奖励不是与现实隔绝的单独数字。

**容易误解：**跨不同任务比较偏好时应注意可比性。

**奖励reward**是对结果或步骤打的分。代码是否通过隐藏测试可以作为一种奖励信号，但若测试太弱，模型可能“绕过考题”而不真正完成目标。


<span id="concept-intro-4"></span>


先认识这里的对象与符号

[PPO、GRPO、advantage](../concepts.md#concept-ppo)
:   这些是策略优化相关概念。PPO常用新旧动作概率比和裁剪来限制更新；GRPO类方法使用组内奖励比较构造优势。优势是相对基线的表现，不是答案正确概率。独立原始差值例：奖励[0,1,1]，减组均值2/3得到[-2/3,1/3,1/3]。算法还可能再归一化，不能直接混用。

**优势advantage**粗略表达某次表现比基线好多少。若一组回答奖励为[0,1,1]，平均2/3，那么相对平均值的原始差值是[-2/3,1/3,1/3]。具体算法还可能归一化或使用不同基线，不能把这个教学差值等同所有实现。


<span id="foundations-19-s3"></span>


## 概率比到底比较什么

旧策略对某选择给0.1，新策略给0.2，比值2表示“相对旧策略更愿意做这个选择”。不是该选择一定正确，也不是整个系统性能翻倍。


<span id="fdiag-19-03"></span>


概率比到底比较什么：逐项辨别

|  |  |
| --- | --- |
| 方案／对象 A | 旧策略πref |
| 方案／对象 B | 新策略πθ |
| 方案／对象 C | 同一回复的概率比 |

**关键区别：**同一回复在两种策略下的概率变化，才能表达相对倾向。

**容易误解：**概率比不是“模型回答长度的比值”。

一整段回答的概率可按下一Token条件概率相乘。很多小概率连乘容易数值变得极小，因此常使用**对数概率**：乘法变为对数之和。比较回答时还要注意长度影响。

## KL散度为什么像一个“不离原来太远”的约束


<span id="concept-intro-1"></span>


先认识这里的对象与符号

[Σ：按下标逐项求和](../concepts.md#concept-sum)
:   Σ是加法的简写。下标指出哪项在变化；没有被求和的下标保持不变。它不是一个额外参数，也不表示把数组拼在一起。独立微例：Σᵢ xᵢyᵢ，x=[1,2]、y=[3,4]，就是1×3+2×4=11。

给两个在相同候选集合上的分布p和q，**KL散度**常写作`Σ_i p_i ln(p_i/q_i)`。它衡量p与q的差异，方向不同结果可不同。


<span id="fdiag-19-04"></span>


**关键区别：**KL提供一种对分布变化程度的约束，避免只追某一类奖励把行为推得过远。

**容易误解：**KL不是两段中文回答的字符差异。

例如p=[0.5,0.5]、q=[0.25,0.75]：`0.5ln2+0.5ln(2/3)≈0.1438`。它不等于两项概率差的绝对值之和，也不是物理距离。

训练中可用这类约束限制策略偏离参考模型太多。系数越强往往越保守，但具体效果要评估，不能把“更强约束”当无条件提高质量。

<span id="fdiag-19-05"></span>


**关键区别：**DPO等偏好方法比较的是给定输入下整段回复概率的相对关系。

**容易误解：**不要把“较好回答”直接当成下一Token的唯一正确标签。


<span id="concept-intro-2"></span>


先认识这里的对象与符号

[sigmoid：把单个数映射到0与1之间](../concepts.md#concept-sigmoid)
:   函数规则是sigmoid(x)=1/(1+exp(-x))。它逐个数计算，不要求同一行结果的总和为1，所以不能用它直接代替多候选softmax。独立微例：sigmoid(0)=0.5；分别算两个0，得到[0.5,0.5]只是巧合，输入[1,1]的两项之和就大于1。

[π、π\_ref与β：偏好目标的符号](../concepts.md#concept-beta-policy)
:   在策略与偏好优化中，π表示条件概率策略，π\_ref表示固定参考策略；β是控制目标尺度或约束强度的设置系数。完整回答的概率由各Token条件概率构成。这里π不是圆周率，β不是LayerNorm的偏移参数。DPO式子的w/l是偏好与非偏好答案标记，不是权重w与层数L。

```
s = β × [(lnπ(w)−lnπ(l)) − (lnπref(w)−lnπref(l))]
损失 = −ln sigmoid(s)
sigmoid(s) = 1/(1+exp(−s))
```

π是当前模型对完整答案的概率，πref是参考模型，β为设置系数。若当前对w、l给0.2、0.1，参考分别给0.1、0.1，β=1，那么s=ln2，sigmoid(s)=2/3，损失约0.4055。

这个公式用偏好对提供训练信号，不意味着完全不需要任何“好坏标准”。也不能直接把它当作调用一次API就可实现的Prompt技巧。


<span id="foundations-19-s6"></span>


## PPO、GRPO为什么不能靠缩写互换


<span id="concept-intro-3"></span>


先认识这里的对象与符号

[RLHF、奖励模型与策略](../concepts.md#concept-rlhf)
:   RLHF泛指利用人类反馈训练行为的流程。奖励模型是对回答等行为打分的模型；策略是实际生成动作的概率模型。两者职责不同，得高奖励不自动等于事实正确。独立例：奖励器偏爱长回答，策略可能学会写长而不更准确；因此奖励判据需要验证。

PPO是一类策略优化方法，常用新旧策略概率比及裁剪等机制控制更新；RLHF某些流程会训练奖励模型和价值估计。GRPO类方法利用同一问题多个采样结果的组内比较形成优势，具体实现与奖励设计仍重要。

“结果奖励”评价最终结果；“过程监督”评价中间步骤。中间过程长不等于正确，额外推理也不是免费。学习到这里再读高级Q021—Q022，你应该能解释每个量从何而来，而不是只会说“用了强化学习”。

### 偏好训练究竟比较哪两个概率比

**输入与条件。**这里**另起一组教学概率**，不接续本节前面用0.2/0.1的公式演示；二者独立地算出相同的相对优势。当前模型对优选回答A、较差回答B给0.6、0.2；参考模型给0.3、0.2，剩余概率属于其他回答。取β=1。

| 步骤与对象 | 内部动作 | 中间结果 / 新状态 |
| --- | --- | --- |
| 1算A相对变化 | `ln(0.6/0.3)` | ln2，约0.693147。 |
| 2算B相对变化 | `ln(0.2/0.2)` | 0。 |
| 3作差并缩放 | β×(A变化−B变化) | 得到偏好间隔ln2。 |
| 4进入sigmoid | `1/(1+exp(−ln2))` | 等于2/3。 |
| 5计算DPO损失 | `−ln(2/3)` | 约0.405465；与参考模型完全相同时是ln2≈0.693147。 |

**把过程连起来。**这不是单看A的绝对概率，而是比较优选与较差回答相对参考模型的变化。

**边界与反例。**例子只解释一对样本的标准DPO目标，不等于复现RLHF训练；真实整段回答概率通常用Token对数概率之和表达。

### KL散度：同两组概率，调换方向会得到不同值

局部核对例：以下输入以本例列出的条件为准，不能把它的中间值接到贯通模型的计算记录中。

**输入与条件。**两个候选词的分布分别为p=[0.8,0.2]、q=[0.5,0.5]。使用自然对数，按KL(p||q)=Σpᵢln(pᵢ/qᵢ)计算。

| 步骤与对象 | 内部动作 | 中间结果 / 新状态 |
| --- | --- | --- |
| 1第一项 | 0.8×ln(0.8/0.5) | 约0.376003。 |
| 2第二项 | 0.2×ln(0.2/0.5) | 约−0.183258；单项可以为负。 |
| 3相加 | 0.376003−0.183258 | KL(p||q)≈0.192745，整体不为负。 |
| 4交换方向 | 0.5ln(0.5/0.8)+0.5ln(0.5/0.2) | KL(q||p)≈0.223144，并不等于前一个值。 |

**把过程连起来。**“限制偏离参考模型”必须明确KL的方向、采样分布和计算位置；它不是通常意义下的对称距离。

**边界与反例。**本例两项概率都大于0，不涉及参考分布为0导致的无限值；后训练目标里的估计方法与本例完整求和可能不同。
